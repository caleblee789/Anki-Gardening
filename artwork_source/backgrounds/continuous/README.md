# Continuous scenery masters

These eight 1448 × 1086 PNG masters were generated with built-in ImageGen from
each theme's original 4:3 painting. Verdant Twilight supplied the continuous
ground reference; its existing runtime image and master remain unchanged in
the adjacent `verdant_twilight` source directory.

`provenance.json` records the exact prompts, reference hashes, generated source
paths and hashes, dimension normalization, retained master hashes, and runtime
WebP hashes. The original ImageGen outputs remain at their recorded paths.
Normalization changes at most one pixel per dimension. Runtime WebPs are
encoded losslessly and decode to the same RGBA pixels as these PNG masters.

Each theme retains its own palette, season, sky features, edge foliage, Nursery,
cottage and path. The planting ground has no painted beds or horizontal seams.
The source catalog keeps the earlier 4:3 paintings for provenance; they are
excluded from the addon package alongside unused 16:9 layouts and authoring
masks. Home artwork, plant sprites and normalized placement geometry are
unchanged.
