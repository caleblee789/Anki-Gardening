# Schema 26 economy, progression, Reviewer HUD, and Verdant Twilight V6 evidence matrix

This is the current working-tree contract for Anki Garden 2.2.0. Automated evidence is
necessary but not sufficient: live acceptance must use the exact rebuilt
archive in a fresh, uniquely named, sync-disabled Anki 26.08 base/profile.
Persisted state is schema 26. Visual evidence uses capture contract v26,
contract schema 2 and scenario schema 3.

## Explicitly deferred

Additional geometry-changing themes, deck mapping, focus
timers, exam mode, social/cloud features, plant death/regression, login-only
rewards, purchasable Boosters, and separate rare-variant progression are outside
the schema-26 release. Four-theme integration and its downstream palette matrices are also
outside this release; the established Garden styling remains unchanged.

## v26 evidence status

The topology is 18 representative/38 full surfaces and two/six sheets. Every
evidence layer requires scenario ID, fixture ID, and one-based step; v25 reuse
is rejected, and visible-copy, overflow, progress, asset-map, Reviewer
exclusion, scroll-state, and lineage assertions are hard gates. Current run
paths, archive and capture hashes, artifact sizes, and validation totals are
recorded only in the
[final 2.1.0 UI audit](ui/final-ui-audit-2.1.0.md). That frozen prerequisite
does not approve 2.2.0. Automated evidence does not change `quality_status:
review-required` or `release_ready: false`; manual
macOS, Windows/Linux, mixed-DPI, forced-colors, screen-reader,
broader-keyboard, and human approval remain open.
